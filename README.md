# 📚 E-Book & Admin Dashboard

A responsive e-book website with separate user and admin functionality, built using HTML, CSS, JavaScript and Bootstrap.

## 🚀 Live Demo

**Live Website:**  
https://e-book-admin-dashboard.netlify.app/

**GitHub Repository:**  
https://github.com/savan-prog/ebook-admin-dashboard

## ✨ Features

### 👤 User Features

- User Registration
- User Login
- User Dashboard
- User Profile
- My Cart
- My Orders
- Browse Books
- Search Books
- Category Filter

### 👨‍💼 Admin Features

- Admin Login
- Admin Dashboard
- Add Book
- Manage Books
- Edit Book
- Manage Orders

### 🔐 Authentication & Access

- Login functionality for users and admins
- Role-based access
- The application identifies whether the logged-in account is an Admin or User and provides the appropriate dashboard and functionality.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## 📖 Book Features

The Books page includes:

- Book search functionality
- Category-based filtering
- Book browsing
